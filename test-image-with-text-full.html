✅ 更改已应用

已完成的优化

  • 移除固定宽高比限制，图片按原始比例显示
  • 使用 object-fit: contain 替代 cover，避免裁剪
  • 支持响应式图片，自动适应不同屏幕尺寸
  • 使用现代 image_url 过滤器替代旧的 img_url
  • 添加完整宽高属性，提升SEO和可访问性
  • 支持移动设备专用图片版本

📱 响应式支持

现在 "First image desktop" 设置将：

  • 在桌面设备显示完整原始图片
  • 在移动设备自动切换到 "First image mobile" 版本
  • 保持图片原始宽高比，不被拉伸或裁剪
  • 自动适应容器宽度，确保最佳显示效果

🎯 使用方法

  1. 进入主题定制器
  2. 找到 "Image with text" 部分
  3. 上传 "First image desktop" 图片
  4. 可选：上传 "First image mobile" 图片用于移动设备
  5. 图片将完整显示，保持原始比例
