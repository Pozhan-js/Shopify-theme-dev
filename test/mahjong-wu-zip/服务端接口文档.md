# 无人自助空间小程序服务端接口文档

## 1. 用户认证相关接口

### 1.1 微信小程序登录
- **接口地址**: `/member/auth/weixin-mini-app-login`
- **请求方式**: POST
- **请求参数**:
  ```json
  {
    "phoneCode": "string", // 手机号授权码
    "loginCode": "string"  // 微信登录码
  }
  ```
- **响应参数**:
  ```json
  {
    "code": 0,
    "data": {
      "accessToken": "string",
      "userId": "number"
    },
    "msg": "string"
  }
  ```

## 接口通用说明

### 响应格式
所有接口统一返回以下格式：
```json
{
  "code": 0,     // 0表示成功，其他表示失败
  "msg": "string", // 错误信息
  "data": {}     // 业务数据
}
```

### 认证方式
需要在请求头中添加：
```
Authorization: Bearer {accessToken}
```

### 状态码说明
- `0`: 成功
- `其他`: 失败，具体错误信息查看msg字段

### 时间格式
所有时间字段统一使用：`YYYY/MM/DD HH:mm` 格式

### 价格单位
所有价格相关字段单位为：元（人民币），保留2位小数

### 分页参数
列表接口统一使用：
- `pageNo`: 页码，从1开始
- `pageSize`: 每页条数
- `total`: 总记录数
